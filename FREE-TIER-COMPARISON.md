## 🔄 How to Switch Providers (If Ever Needed)

If you ever want to switch from Groq to another provider:

### Step 1: Get New API Key
- Sign up for alternative provider
- Generate API key

### Step 2: Update Config Files
**In `teacher-chat/config.php` and `parent-chat/config.php`:**

**For Google Gemini:**
```php
define('GROQ_API_ENDPOINT', 'https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash-lite:generateContent');
define('GROQ_API_KEY', 'YOUR_GOOGLE_API_KEY');
define('GROQ_MODEL', 'gemini-2.5-flash-lite');
```

**For OpenRouter:**
```php
define('GROQ_API_ENDPOINT', 'https://openrouter.ai/api/v1/chat/completions');
define('GROQ_API_KEY', 'YOUR_OPENROUTER_KEY');
define('GROQ_MODEL', 'meta-llama/llama-3.3-70b-instruct');
```

### Step 3: Test and Deploy
- Test locally or on staging
- Deploy when working

**Note:** May need to adjust `chat.php` slightly for different API formats
