## ✨ نظرة عامة

منصة تعليمية تفاعلية مصممة خصيصاً لطلاب السنة الرابعة آداب في تونس، توفر موارد تعليمية شاملة للمحورين الأدبيين العربيين مع تطبيقات موجهة ومنهجية علمية.

### 📖 المحاور المتوفرة

#### المحور الأول: شعر الحماسة (القرنان 3-4 هـ)
- دراسة معمقة لثلاثة شعراء: أبو تمام، المتنبي، ابن هانئ الأندلسي
- تحليل النصوص الشعرية
- الخصائص الفنية (إيقاع، معجم، صور، أساليب)
- 5 تحاليل نصوص + 5 مواضيع مقالات موجهة

#### المحور الثاني: المنزع العقلي عند الجاحظ
- المنهج العلمي الجاحظي (6 أسس)
- تحليل النصوص الحجاجية
- الأسلوب الجاحظي (10 خصائص)
- 5 تحاليل نصوص حجاجية + 5 مواضيع مقالات موجهة

## <a id="features"></a>🎯 الميزات الرئيسية

### ✅ محتوى تعليمي شامل
- **12 ملف تعليمي** منظم ومُفصل
- **منهجية علمية** واضحة لتحليل النصوص
- **ملخصات سريعة** (Cheat Sheets) لكل محور
- **10 تطبيقات موجهة** مع دليل خطوة بخطوة

### 🔊 تقنية TTS (Text-to-Speech)
- **استماع للنصوص العربية** بصوت أدبي واضح
- **تفعيل/تعطيل سهل** من واجهة المستخدم
- **قراءة تلقائية** للعناوين، الفقرات، والاقتباسات

### 📱 تصميم متجاوب (Responsive)
- **واجهة جميلة وحديثة** مع Tailwind CSS
- **تجربة مثالية** على الهاتف والحاسوب
- **تصميم عربي أصيل** (RTL) مع خطوط Noto Naskh Arabic

### 🎨 تجربة مستخدم متميزة
- **ألوان ذهبية أنيقة** تعكس قيمة المحتوى
- **رسوم متحركة سلسة** (Smooth Animations)
- **تنقل سهل** بين المحاور والملفات
- **بطاقات تفاعلية** (Interactive Cards)

### 📧 CTAs تفاعلية
- **اشتراك في النشرة الإخبارية** للحصول على تحديثات
- **تقييمات على وسائل التواصل** (Google, Facebook, Instagram)
- **مشاركة سهلة** للمحتوى

## <a id="installation"></a>⚙️ التثبيت والإعداد

### المتطلبات
- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone <repository-url>
cd bac-lettres-app
```

2. **تثبيت التبعيات**
```bash
npm install
```

3. **تشغيل سيرفر التطوير**
```bash
npm run dev
```

4. **فتح المتصفح**
```
افتح: http://localhost:5173
```

### البناء للإنتاج

```bash
# بناء المشروع
npm run build

# معاينة البناء
npm run preview
```

## <a id="usage"></a>📖 دليل الاستخدام

### 1. الصفحة الرئيسية
- استعرض المحاور المتوفرة
- اقرأ عن الميزات
- اشترك في النشرة الإخبارية

### 2. صفحات المحاور
- اختر المحور المناسب
- استعرض الملفات التعليمية
- ابدأ بالملف الأول أو اختر ملفاً محدداً

### 3. قارئ المحتوى
- **تفعيل TTS:** اضغط على زر "تفعيل الاستماع"
- **الاستماع:** مرر فوق النص واضغط على 🔊
- **التنقل:** استخدم الأزرار في الأسفل للانتقال بين الملفات

## 🔧 التخصيص

### تحديث روابط النشرة الإخبارية

افتح `src/components/common/NewsletterCTA.jsx` وحدث:
```javascript
const NEWSLETTER_FORM_URL = 'YOUR_ACTUAL_FORM_URL';
```

### تحديث روابط وسائل التواصل

افتح `src/components/common/SocialCTAs.jsx` وحدث:
```javascript
const GOOGLE_REVIEW_URL = 'YOUR_GOOGLE_REVIEW_URL';
const FACEBOOK_URL = 'YOUR_FACEBOOK_PAGE_URL';
const INSTAGRAM_URL = 'YOUR_INSTAGRAM_PAGE_URL';
```

### تخصيص الألوان

في `tailwind.config.js`، عدل ألوان `gold`:
```javascript
colors: {
  gold: {
    500: '#f59e0b',  // لون رئيسي
    600: '#d97706',  // لون عند التمرير
    // ... بقية الألوان
  }
}
```
