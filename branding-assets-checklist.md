### 2.2 How to Find HEX Codes

**If you don't know your HEX codes:**

**Method 1: From Existing Website**
1. Visit smarthub.com.tn
2. Right-click on colored element
3. Select "Inspect" or "Inspect Element"
4. Look for `color:` or `background-color:` in CSS
5. Copy the HEX code (e.g., #0066CC)

**Method 2: From Image/Logo**
1. Use online tool: https://imagecolorpicker.com/
2. Upload your logo
3. Click on colors to get HEX codes

**Method 3: Color Picker Tool**
- Windows: Use built-in Paint or free tool like ColorPic
- Mac: Use Digital Color Meter (built-in)
- Online: https://htmlcolorcodes.com/color-picker/

**Method 4: Brand Guidelines**
- Check if you have existing brand guidelines document
- Often includes exact color codes
