## Key Findings

### Pedagogical Approach
- **Learner-centered:** Student is at the core of the learning process
- **Communicative:** Language as a means of communication
- **Contextual:** Grammar taught in context, not isolation
- **Cooperative:** Emphasis on pair work and group activities
- **Skills-integrated:** Reading, writing, listening, speaking combined

### Common Structure Across Grades
Each lesson follows consistent pattern:
1. **Get Ready:** Topic introduction, activate prior knowledge
2. **Learn More About It:** Reading/listening passage
3. **Grammar Point:** Context-based grammar instruction
4. **Comprehension Check:** Understanding and analysis
5. **Language Work:** Practice exercises
6. **Pronunciation:** Sound/stress/spelling focus
7. **Writing/Project Work:** Application and production

### Grammar Progression
- **Grade 6:** Present simple/continuous, past simple, future, modals, comparatives
- **Grade 7:** Past continuous, present perfect, conditionals, passive voice (intro)
- **Grade 8:** Present perfect continuous, passive voice, reported speech, relative clauses
- **Grade 9:** Advanced tenses, conditionals, compound forms, complex structures

### Assessment Framework
- **Formative:** Comprehension checks, language work, pair/group activities
- **Summative:** Module tests, writing tasks, project presentations
- **Skills-based:** All four skills assessed (reading, writing, listening, speaking)
